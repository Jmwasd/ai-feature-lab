## 작업

리포트를 브라우저 인쇄로 PDF에 담을 수 있게 만든다. **서버 렌더링 PDF를 만들지 마라** (ADR-008).

1. `globals.css`에 `@media print` 규칙:
   - `section { break-inside: avoid; }` — 섹션이 페이지 중간에서 잘리지 않게
   - `.no-print { display: none; }`
   - **다크 서피스를 인쇄 시 라이트로 반전한다** (아래 2번). 이것이 이 step의 핵심이다

2. **다크 서피스 반전 — 반드시 구현하라.**

   리포트의 반복 결제 카드는 `bg-ink`(#0a0b0d) 배경에 흰 텍스트다. 브라우저는 기본적으로 배경색을 인쇄하지 않으므로, **아무 처리도 하지 않으면 흰 종이에 흰 글씨가 찍혀 발견 1번 카드가 통째로 사라진다.**

   `@media print`에서 다크 카드에 한해 이렇게 뒤집는다:

   ```
   배경   #0a0b0d       →  #ffffff
   텍스트  #ffffff       →  #0a0b0d (ink)
   보조 텍스트 #a8acb3   →  #5b616e (text-body)
   구분선  #2a2d33       →  #dee1e6 (line)
   테두리  없음          →  1px solid #dee1e6   ← 카드 경계가 사라지지 않게
   ```

   구현 방식은 재량이나, **다크 카드를 식별할 수 있는 클래스 하나(예: `.surface-dark`)를 컴포넌트에 달고 그 클래스에만 반전 규칙을 적용하라.** 요소마다 개별 print 오버라이드를 흩어 놓지 마라.

   `print-color-adjust: exact`로 검은 배경을 그대로 찍는 방식은 채택하지 않는다. 이유: A4 한 면을 잉크로 채우고, 사용자가 브라우저 설정에서 배경 인쇄를 끄면 다시 흰 글씨가 된다. 반전은 그 설정과 무관하게 항상 읽힌다.

3. `no-print` 클래스를 붙일 대상:
   - `UploadPanel` 전체
   - `OverrideControl`의 입력 UI — 다만 **사용자가 지정한 값은 인쇄돼야 한다.** 선택된 결과는 텍스트로 남기고 셀렉트 박스만 숨긴다
   - 인쇄 버튼 자체

4. 인쇄 버튼 — `window.print()` 호출. `no-print`를 단다

5. 인쇄용 헤더 — 화면에는 안 보이고 인쇄 시에만 나오는 한 줄: 리포트 기간과 생성 시각. 파일로 남았을 때 무엇인지 알 수 있어야 한다

## 금지사항

- 서버 렌더링 PDF(Puppeteer, `@react-pdf`, `jsPDF`)를 도입하지 마라. 이유: 저장 없는 정책에 헤드리스 브라우저는 과한 장치다 (ADR-008)
- 인쇄용 별도 라우트/페이지를 만들지 마라. 이유: 두 벌이 되면 한쪽이 조용히 낡는다. 같은 DOM에 `@media print`만 얹어라
- `print-color-adjust: exact`로 검은 배경을 그대로 찍지 마라. 반전으로 처리한다. 이유: A4 한 면을 잉크로 채우고, 사용자가 브라우저 배경 인쇄를 끄면 다시 흰 글씨가 된다
- 다크 카드를 `no-print`로 숨겨서 문제를 회피하지 마라. 이유: 반복 결제는 발견 1번이다. 인쇄물에서 빠지면 리포트의 핵심이 통째로 사라진다
- 사용자 보정 결과를 인쇄에서 숨기지 마라. 입력 위젯만 숨긴다. 이유: 보정값이 빠지면 인쇄된 총액의 근거가 사라진다
