# Architecture Decision Records

되돌리기 어렵거나 여러 기능과 step에 영향을 주는 기술 결정만 기록한다.
단순한 구현 선택이나 쉽게 바꿀 수 있는 세부 사항은 ADR로 만들지 않는다.

## ADR-1: git 데이터는 git CLI를 호출해 파싱한다

- **결정**: `child_process.execFile`로 `git` 명령을 직접 호출하고 출력을 파싱한다. isomorphic-git, nodegit, simple-git 같은 라이브러리를 쓰지 않는다.
- **근거**: 로컬 도구라 사용자 컴퓨터에 git이 있다고 전제할 수 있다. `--numstat`, `--pretty=format:` 출력은 안정적이고, 이름 변경 탐지·머지 커밋 처리처럼 까다로운 부분을 git이 이미 맞게 해준다. 네이티브 빌드(nodegit)나 자체 diff 계산(isomorphic-git)은 큰 저장소에서 느리거나 설치가 깨진다.
- **영향/제약**: git이 없거나 PATH에 없으면 동작하지 않는다 — 화면에서 그 사실을 설명해야 한다. 파싱이 이 프로젝트의 진짜 위험 지점이므로, `lib/git/`만 실제 저장소 픽스처로 테스트한다. 셸 보간 없이 인자 배열로만 호출한다.

## ADR-2: 로그인은 접근 제어가 아니라 화면 흐름이다

- **결정**: 랜딩 → 구글 로그인 → 서비스 화면 순서를 만들되, 이 도구는 localhost에만 바인딩되는 단일 사용자 도구로 남는다. 로그인은 사용자 식별이나 권한 분리를 하지 않는다.
- **근거**: 읽는 대상이 실행한 사람 본인의 로컬 git 저장소다. 로그인으로 지킬 비밀이 없다. 그럼에도 로그인 흐름을 두는 이유는 서비스형 화면 구성을 갖추기 위해서다.
- **영향/제약**: 구글 계정 제한(화이트리스트·도메인)을 두지 않는다. 권한·역할·감사 로그 같은 기능을 여기서 파생시키지 마라. 세션이 있어도 서버를 외부에 노출하는 설정을 추가하지 마라.

## ADR-3: 세션은 서명된 HttpOnly 쿠키에만 담는다

- **결정**: `POST /api/session`이 구글 ID 토큰을 서버에서 검증하고, `AUTH_SECRET`으로 서명한 세션을 HttpOnly 쿠키로 굽는다. 세션 저장소(메모리 테이블·파일·DB)는 만들지 않는다. 게이트는 `middleware.ts` 한 곳이다.
- **근거**: 저장소가 없으니 서버를 재시작해도 로그인이 유지되고, 개발 중 잦은 재시작에 방해받지 않는다. 게이트가 서버에 있으면 주소창으로 `/repo/[sha]`에 직접 들어오는 경로도 같은 규칙을 탄다.
- **영향/제약**: 세션 만료는 구글 ID 토큰의 `exp`(약 1시간)를 그대로 따른다. 만료되면 `/?next=<원래 경로>`로 보내고 재로그인 후 그 경로로 복귀한다. `next`는 `/`로 시작하는 내부 경로만 허용한다. `AUTH_SECRET`이 없으면 서버가 뜨지 않는다.

## ADR-4: LLM에 보내는 diff는 200KB에서 자르고, 잘린 사실을 표시한다

- **결정**: 커밋 요약 입력은 메시지와 파일별 numstat 전체 + diff 본문 200KB까지로 제한한다. 초과하면 자르고, 프롬프트와 화면 양쪽에 잘렸음을 명시한다.
- **근거**: 상한이 없으면 대형 리팩터링 커밋 하나가 컨텍스트를 채우고 비용을 튀긴다. 반대로 큰 커밋에서 요약을 아예 생략하면 정작 가장 궁금한 커밋이 비어버린다. 파일 목록과 numstat은 작으므로 항상 전부 보내 "무엇이 바뀌었는지"의 골격은 유지한다.
- **영향/제약**: 요약은 diff 앞부분에 치우칠 수 있다. 화면에 그 한계를 적지 않고 자르는 것은 금지다.

## ADR-5: 포트는 3000으로 고정한다

- **결정**: CLI는 빈 포트를 찾지 않고 3000만 쓴다. 이미 점유돼 있으면 에러를 내고 종료한다.
- **근거**: Google Identity Services는 승인된 JavaScript 원본을 사전 등록해야 한다. 포트가 바뀌면 등록된 원본과 달라져 로그인이 실패한다.
- **영향/제약**: 3000을 쓰는 다른 개발 서버와 충돌한다. 포트를 바꾸려면 Google Cloud 콘솔의 원본 등록도 함께 바꿔야 한다는 안내를 에러 메시지에 넣는다.
