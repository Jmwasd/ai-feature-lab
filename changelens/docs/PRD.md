# PRD: changelens

## 목표
로컬 git 저장소의 변경 이력을, 커밋 메시지만으로는 알 수 없는 "실제로 무엇을 어떻게 바꿨는지"까지 한 화면에서 읽게 한다.

## 사용자
자기 컴퓨터에서 직접 실행하는 개발자 한 명. 터미널에서 `node bin/changelens.mjs`로 띄우고 브라우저로 본다. 여러 사람이 동시에 쓰는 상황은 상정하지 않는다.

## 핵심 기능
1. **랜딩 페이지** — 제품 한 줄 소개와 기능 3개 소개 섹션, 그리고 구글로 시작하기 버튼.
2. **구글 로그인** — Google Identity Services 버튼으로 받은 ID 토큰을 서버가 검증하고 세션 쿠키를 발급한다. 로그인 전에는 서비스 화면으로 들어갈 수 없다.
3. **커밋 목록 화면(`/repo`)** — 화면 맨 위에 지표 4종(전체 커밋 수 / 첫·마지막 커밋 기간 / 총 추가·삭제 줄 / 기여자 수)을 보여주고, 그 아래에 커밋 하나를 요약 카드 한 장으로 묶어 시간순으로 늘어놓는다. 카드에는 제목, 날짜, 바뀐 파일 수, 추가·삭제 줄 수가 들어간다. 현재 브랜치(HEAD)의 조상 커밋 전체를 대상으로 하고 50개씩 "더 보기"로 이어 붙인다.
4. **커밋 상세 화면(`/repo/[sha]`)** — 그 커밋이 무엇을 어떻게 바꿨는지 파일 목록과 파일별 diff까지 보여준다. 함께 Claude가 diff를 읽고 쓴 "이 커밋이 실제로 한 일" 요약을 맨 위에 보여준다.

## MVP 제외 사항
- 커밋 검색·필터 (메시지, 작성자, 경로)
- 화면에서의 브랜치 전환 — 현재 브랜치만 본다
- 파일 단위 히스토리와 blame
- 두 커밋을 골라 비교하는 화면
