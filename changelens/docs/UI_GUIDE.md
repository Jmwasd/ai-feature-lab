# UI 디자인 가이드 — 옮김

디자인 기준은 `design` 스킬로 옮겼다. 이 파일은 더 이상 기준이 아니다.

- 규칙 원본: [`.claude/skills/design/guide.md`](../.claude/skills/design/guide.md)
- 적용 절차와 검사기: [`.claude/skills/design/SKILL.md`](../.claude/skills/design/SKILL.md)
- 하네스: `index.json`에서 `"ui": true`인 step에 `execute.py`가 스킬을 넣는다.

이 파일에 규칙을 다시 적지 마라. 두 벌이 되면 어느 쪽이 맞는지 알 수 없다.

이전 가이드에서 새 가이드와 부딪히지 않는 규칙은 `guide.md` §9로 옮겼다. 원문은 git 이력에 있다:
`git show efc0f48:changelens/docs/UI_GUIDE.md`
