# UI_GUIDE — changelens

UI가 있는 화면을 만들거나 고칠 때 따르는 기준. 한 사람이 로컬에서 돌리는 읽기 전용 도구이므로,
화면은 diff와 숫자를 방해하지 않는 선에서만 존재한다. 장식은 없고, 강조는 앰버 하나로만 한다.

> 디자인 규칙의 단일 원본이다. `design` 스킬(`SKILL.md`)과 하네스의 UI step(`"ui": true`)이 이 파일을 읽는다.
> `docs/UI_GUIDE.md`나 step 파일에 복제하지 마라.
>
> **우선순위: §1–7 → §8 → §9.** §8은 Claude Design 프로토타입을 §1–7에 맞춰 옮긴 화면 구성이고,
> §9는 이전 `docs/UI_GUIDE.md`에서 앞 절과 부딪히지 않는 규칙만 옮겨 온 보충이다. 부딪히면 앞 절을 따른다.

---

## 1. 원칙

- **본문은 데이터다.** 커밋 제목, sha, 경로, diff가 화면의 주인공이다. 컨테이너·아이콘·배지는 그것들을 구분하는 데 필요한 만큼만 쓴다.
- **강조는 하나.** 앰버(`--accent`)는 한 화면에 한두 곳 — 주 버튼, 활성 상태, 로고. 제목 색, 테두리, 배경 워시로 쓰지 않는다.
- **깊이는 밝기 차로.** 그림자 없음. `canvas → surface` 밝기 차이와 1px 헤어라인만으로 층을 만든다.
- **초록·빨강은 의미다.** 추가/삭제, 증가/감소에만 쓴다. 성공/실패 같은 일반 상태에 전용하지 않는다.
- **글자는 안 움직인다.** 스크롤 애니메이션, 등장 효과 없음. 전환은 색상 150ms 선형까지.

|---|---|---|
| `--canvas` | `#0d1013` | 페이지 바닥 |
| `--surface` | `#16191e` | 카드, 상단 바, 패널 |
| `--surface-raised` | `#22262d` | 카드 안의 카드, 비활성 버튼 |
| `--hairline` | `#262b33` | 1px 테두리·구분선 (모든 분리는 이걸로) |
| `--hairline-soft` | `#1e222a` | 목록 안의 행 구분선 |
| `--ink` | `#ffffff` | 제목, 지표 값 |
| `--body` | `#e6e8eb` | 본문, 카드 제목 |
| `--body-dim` | `#b4bcc6` | 설명 문단 |
| `--muted` | `#7b848f` | 메타, 라벨, 캡션 (이보다 어두운 텍스트는 쓰지 않는다) |
| `--accent` | `#ffb020` | 주 버튼, 활성 배지, 로고, 인라인 링크 |
| `--accent-ink` | `#0d1013` | 앰버 위 글자 (항상 어두운 잉크) |
| `--add` | `#3fb950` | 추가 줄 수, diff 추가 |
| `--del` | `#f0616d` | 삭제 줄 수, diff 삭제, 에러 문구 |
| `--diff-add-bg` | `#11261a` | diff 추가 줄 배경 |
| `--diff-del-bg` | `#2a1418` | diff 삭제 줄 배경 |
| `--diff-add-fg` | `#5ddb8a` | diff 추가 줄 글자 |
| `--diff-del-fg` | `#ff8a94` | diff 삭제 줄 글자 |

**대비 하한:** 본문 텍스트는 배경 대비 4.5:1 이상. `--muted`(#7b848f)가 `--surface` 위에서 기준선이며,
그보다 어두운 회색은 텍스트로 쓰지 않는다. 장식 글리프(›, 구분점)도 `--muted`까지만 내린다.

**금지:** 그라디언트 배경, 앰버 배경 위 흰 글자, 초록/빨강 카드 배경, 반투명 블러 표면.

## 3. 타입

두 서체만 쓴다. 섞지 않는다.

- **IBM Plex Sans** — 제목, 문단, 버튼 라벨, 라벨
- **IBM Plex Mono** — 숫자, sha, 파일 경로, 날짜, diff, 명령어

| 역할 | 크기 / 굵기 / 행간 | 서체 |
|---|---|---|
| 랜딩 h1 | 48 / 700 / 1.1, 자간 −0.5 | Sans |
| 화면 제목 (h1) | 24 / 600 / 1.3 | Sans |
| 섹션 제목 (h2) | 18 / 600 / 1.4 | Sans |
| 카드 제목 | 15 / 600 / 1.4 | Sans |
| 본문 | 14–16 / 400 / 1.6–1.7 | Sans |
| 메타·캡션 | 12 / 400 / 1.5 | Mono |
| 지표 값 | 28 / 600 / 1.1 | Mono |
| sha·경로 | 13 / 400 | Mono |
| diff 줄 | 13 / 400 / 1.7, `white-space: pre` | Mono |
| 버튼 라벨 | 14–15 / 600 | Sans |
| 섹션 인덱스 (`01 · 원칙`) | 12 / 400, 자간 0.5 | Mono, 앰버 |

커밋 제목은 굵기로 올리고 크기로 올리지 않는다. 자간은 20px 이상에서만 음수.

## 4. 간격·모서리·레이아웃

- **기준 단위 4px.** 쓰는 값: 4 · 8 · 12 · 16 · 20 · 24 · 32 · 48 · 64 · 96.
- **카드 안 여백:** 20–24px. 목록 행은 세로 12–16px.
- **섹션 사이:** 48–56px. 큰 밴드(랜딩 히어로)는 위아래 96px.
- **콘텐츠 폭:** 1080px 고정 상한, 좌우 여백 24px.
- **모서리:** 버튼·입력 6px, 카드·패널 12px, 배지·필터 칩 9999px. 각진 모서리는 쓰지 않는다.
- **그림자:** 없음.
- **반응:** 지표 4종은 `repeat(auto-fit, minmax(170px, 1fr))`로 자연스럽게 2×2로 접힌다.
  커밋 카드는 한 줄 유지, 제목만 말줄임. diff 블록은 가로 스크롤(`overflow-x: auto`)하고 줄바꿈하지 않는다.

## 5. 컴포넌트 규칙

**버튼**
- 주 버튼: 앰버 배경 + 어두운 잉크, 48px 높이, 6px 라운드. 화면당 하나.
- 보조: 투명 배경 + `--hairline` 테두리, 40px.
- 작은 보조(뒤로가기 등): 32px.
- 비활성: `--surface-raised` 배경 + `--muted` 글자, `cursor: not-allowed`.
- 라벨은 한두 단어, 마침표 없음: `로그인`, `50개 더 보기`, `← 커밋 목록`.

**지표 카드** — 라벨 12 → 값 28 mono → 보조 12 mono. 목록 맨 위 4개 고정. 감소 수치만 `--del`.

**커밋 카드** — 카드 전체가 링크. 제목 한 줄 말줄임, 그 아래 메타는 `sha · 작성자 · 날짜 · 파일 수` 순서로 mono 12.
오른쪽에 `+추가 / −삭제`와 `›`. 카드 사이 간격 8px.

**요약 카드 (Claude)** — 상세 화면 맨 위. `CLAUDE 요약` 배지(앰버 배경, mono 11, 대문자)로 생성물임을 명시하고,
문단 하나 + 불릿 2–3개. 추측을 쓰지 않고 diff에서 확인된 것만 적는다.

**파일 목록** — 한 행에 경로(mono 13)와 `+n / −n`. 행 구분선 `--hairline-soft`.

**diff 블록** — 파일당 카드 하나. 헤더에 경로와 헝크 범위(`@@ -1,8 +1,34 @@`).
줄 배경/글자는 diff 토큰을 쓰고, 좌우 여백 20px, 줄바꿈 금지.

**빈 상태 / 차단** — 가운데 정렬, 상태 코드를 mono로 먼저(`401 · 세션 없음`), 제목 한 줄, 설명 한 문단, 행동 버튼 하나.

## 6. 카피

- 평서문 종결(`~한다`, `~다`). 느낌표 없음. 이모지 없음.
- 에러는 원인이 아니라 할 일을 쓴다: "로그인해야 저장소를 볼 수 있습니다".
- 숫자는 자릿수 구분 쉼표, 증감은 `+` / `−`(U+2212, 하이픈 아님).
- 날짜는 `2026-09-19 14:22`, 기간은 en dash: `2025-07-02 → 2026-09-19`.
- 로컬 도구임을 한 번은 밝힌다: "내 컴퓨터에서만 돕니다."

## 7. 검토 체크리스트

- [ ] 앰버가 이 화면에 두 곳 이하로만 있나
- [ ] 그림자를 쓴 요소가 없나
- [ ] 12px 텍스트가 `--muted`보다 어둡지 않나
- [ ] 숫자·sha·경로·diff가 전부 Mono인가
- [ ] 초록·빨강이 증감/diff 외의 의미로 쓰이지 않았나
- [ ] 카드 여백이 20–24px, 모서리가 6/12/9999 중 하나인가
- [ ] 좁은 폭에서 지표가 접히고 diff가 가로 스크롤되나

## 8. 화면 (Claude Design 프로토타입 기준)

원본: [changelens 프로토타입](https://claude.ai/artifact/CaZ5dkLwe4z9arEUr5wthi) — 랜딩 · 로그인 · 차단 · `/repo` · `/repo/[sha]`.
아래 값은 프로토타입을 §1–7에 맞춰 옮긴 것이다. 프로토타입과 달라진 자리는 절 끝 표에 있다.
프로토타입 맨 위의 `화면` 칩 줄은 시안을 넘겨 보는 도구라 만들지 않는다. 단위는 px.

- 인라인 링크: `--accent`, hover 때만 밑줄. 텍스트 선택: `--accent` 바탕 + `--accent-ink`.

## 9. 보충 규칙 (이전 가이드에서 옮김)

§1–8이 다루지 않는 부분만 남겼다. 부딪히면 앞 절을 따른다.

- **다크 한 벌.** 라이트 모드는 만들지 않는다. 토큰을 두 벌 유지하지 마라.
- **토큰으로만 칠한다.** §2 토큰을 `app/globals.css`의 `:root`에 같은 이름으로 정의하고 Tailwind 테마에 연결한다.
  임의 색 값(`bg-[#…]`)과 Tailwind 기본 팔레트(`gray-500` 등)를 쓰지 않는다.
- **sha는 앞 7자만** 보인다.
- **상단 바**는 `sticky top-0`로 고정한다. 무엇을 둘지는 §8.
- **커밋 카드**는 커밋 하나당 정확히 한 장.
- **diff**
  - 파일별로 접을 수 있다. 기본은 펼침, 300줄을 넘는 파일은 접힌 채로 시작한다.
  - 구문 강조는 하지 않는다.
  - 줄 앞 `+`/`-` 기호를 git 출력 그대로 남긴다 — 색으로만 뜻을 전하지 않는다. §6의 `−`(U+2212)는 화면 문구의 숫자에만 적용한다.
  - 줄 번호를 둔다면 그 색도 §2 대비 하한을 지킨다. `--muted`는 `--diff-add-bg` 위에서 4.21:1로 하한에 못 미친다.
- **요약 카드 상태**
  - 불러오는 동안 스켈레톤 3줄. 움직이지 않는다(§1).
  - 실패하면 이 카드만 한 줄 안내로 접히고, 아래 파일 목록과 diff는 그대로 보인다.
  - diff가 잘렸으면(ADR-4) 카드 아래쪽에 캡션(§3)으로 그 사실을 적는다.
- **빈 상태·차단**에는 아이콘·일러스트를 쓰지 않는다.
- **더 보기** — 불러오는 동안 비활성(§5) + `불러오는 중`. 무한 스크롤을 쓰지 않는다.
- **GIS 로그인 버튼** — 구글이 렌더하므로 스타일을 덮어쓰지 않고 `--surface` 위에 그대로 올린다.
- **포커스 링** — 지우지 않는다. `--accent` 2px.
- **클릭 대상** — 최소 높이 40px. §5의 작은 보조 버튼(32px)은 예외.
