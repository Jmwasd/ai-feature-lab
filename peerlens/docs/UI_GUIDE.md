# UI 디자인 가이드 — M0

## 디자인 원칙

1. **도구처럼 보인다.** 화면의 주인공은 관련 근거와 숫자이며 장식은 없다.
2. **한 화면에서 판단한다.** 검색 종목과 최대 5개 관련주를 한 표에서 비교한다.
3. **모르는 것은 모른다고 쓴다.** 빈 데이터는 “데이터 없음”, 상관 표본이 부족하면 “표본 부족”으로 표시한다.

## 금지 사항

| 금지 사항 | 이유 |
|-----------|------|
| backdrop-filter, 글래스모피즘 | 데이터 도구에 불필요한 장식 |
| gradient-text, gradient orb, 글로우 애니메이션 | 정보 위계를 흐림 |
| 보라·인디고 브랜드 색상 | 색은 데이터 의미에만 사용 |
| 모든 요소의 큰 둥근 모서리 | 템플릿 같은 인상을 만듦 |
| 차트·카드·배지의 장식용 아이콘 | M0의 관련주 비교에 기여하지 않음 |
| 로그인 CTA, 블러 게이트 | M0에는 계정과 리포트가 없음 |

## 색상

| 용도 | 값 |
|------|-----|
| 페이지 | `#0b0b0d` |
| 카드 | `#141417` |
| 표 헤더 / 구분 배경 | `#1c1c20` |
| 보더 | `#2a2a30` |
| 주 텍스트 | `text-white` |
| 본문 | `text-neutral-300` |
| 보조 / 데이터 없음 | `text-neutral-500` |
| 양수 / 성장 | `#22c55e` |
| 음수 / 감소 | `#ef4444` |

채도 있는 색은 녹색·빨강뿐이다. 이는 주가 등락이 아니라 재무 수치의 증감만 나타낸다.

## 컴포넌트

### 검색창

```
rounded-lg bg-[#141417] border border-[#2a2a30] px-4 py-3
focus: border-neutral-600 (링 없음)
```

- 지원 50개 종목의 티커와 회사명만 자동완성한다.
- 자연어 질문·테마 키워드 입력을 받지 않는다.

### 비교표

```
헤더:  text-xs font-medium text-neutral-400 border-b border-[#2a2a30] py-2
셀:    text-sm text-neutral-200 tabular-nums py-2.5
행:    hover:bg-[#1c1c20]
기준행: bg-[#1c1c20] text-white font-medium — 항상 최상단
```

- 행은 검색 종목 1개와 관련주 최대 5개다.
- 수치는 최신 분기 매출, 매출 YoY, 최근 연간 영업현금흐름 세 열만 둔다.
- 모든 숫자는 `tabular-nums`와 우측 정렬을 적용한다. 텍스트는 좌측 정렬한다.
- `0`이나 `—`로 결손을 감추지 않는다. 항상 “데이터 없음”을 쓴다.

### 관련성 표시

```
근거:     text-sm text-neutral-300
상관계수: text-sm tabular-nums (0.87 형식, 소수 둘째 자리)
표본 수:  text-xs text-neutral-500 — "20분기"
표본 부족: text-neutral-500 — "표본 부족"
```

상관계수 옆에는 표본 수를 항상 병기한다. “검증됨”, “강력 추천”, “좋은 종목” 같은 평가 문구를 쓰지 않는다.

### 카드

```
rounded-lg bg-[#141417] border border-[#2a2a30] p-5
```

카드는 종목 헤더와 관련주 표처럼 정보 묶음이 있을 때만 사용한다. 모든 문장을 카드로 감싸지 않는다.

## 레이아웃

- 전체 너비: `max-w-5xl`
- 좌측 정렬 기본. 랜딩 검색 영역만 중앙 정렬을 허용한다.
- 간격: 요소 간 `gap-3~4`, 섹션 간 `space-y-8`
- 종목 상세 순서: 종목 헤더(기준일 포함) → 관련주 근거·상관 표시 → 3개 지표 비교표 → 데이터 한계 및 면책 고지
- 5년 추이, 성장률 차트, 리포트 섹션을 만들지 않는다.

## 타이포그래피

본문 폰트는 Pretendard를 쓴다. 숫자는 전역 `font-variant-numeric: tabular-nums`를 적용한다.

| 용도 | 스타일 |
|------|--------|
| 페이지 제목 | `text-3xl font-semibold text-white` |
| 티커 | `text-lg text-neutral-400 tabular-nums` |
| 섹션 제목 | `text-sm font-medium text-neutral-400 uppercase tracking-wide` |
| 본문 / 근거 | `text-[15px] text-neutral-300 leading-relaxed` |
| 지표 수치 | `text-sm text-neutral-200 tabular-nums` |
| 기준일 / 출처 | `text-xs text-neutral-500` |

## 애니메이션과 아이콘

- 페이지 진입에 `fade-in` 0.2초만 허용한다.
- 호버 확대·이동·그림자 변화, 차트 선 그리기, 로딩 장식은 만들지 않는다.
- SVG 아이콘은 검색과 외부 SEC 링크처럼 기능이 있을 때만 사용한다. `strokeWidth`는 1.5다.

## 툴팁

전문 용어에만 물음표 아이콘을 둔다. M0 대상은 매출 성장률, 영업현금흐름, 상관계수 세 개다.

```
트리거: text-neutral-500 hover:text-neutral-300, 12px 물음표 아이콘
본문:   rounded-md bg-[#1c1c20] border border-[#2a2a30] px-3 py-2 text-xs text-neutral-300 max-w-xs
```

설명은 정의만 쓰며 투자 판단을 유도하지 않는다.

## 면책 고지

모든 페이지 하단에 표시한다.

```
text-xs text-neutral-500 border-t border-[#2a2a30] pt-4
```

문구: 본 서비스가 제공하는 정보는 공개 공시 자료와 자동 생성된 관련성 정보를 정리한 참고 자료이며 투자 자문이 아닙니다. 자동 생성 결과와 공시 데이터에는 오류 또는 누락이 있을 수 있습니다. 투자의 최종 판단과 책임은 이용자 본인에게 있습니다.
