# UI 디자인 가이드

## 디자인 원칙

1. **도구처럼 보여야 한다.** 마케팅 페이지가 아니라 매일 쓰는 대시보드다. 화면의 주인공은 숫자와 차트이고, 장식은 전부 방해물이다.
2. **정보 밀도를 낮추지 않는다.** 대상은 중급 투자자다. 여백으로 화면을 채우기보다 한 화면에서 비교가 끝나게 만든다. 대신 정렬과 위계로 읽기 쉽게 한다.
3. **모르는 것은 모른다고 쓴다.** 빈 데이터를 그럴듯한 추정치나 대시(—) 하나로 얼버무리지 않고 "데이터 없음"이라고 적는다. 상관계수 옆에는 항상 표본 수를 붙인다.

## AI 슬롭 안티패턴 — 하지 마라

| 금지 사항 | 이유 |
|-----------|------|
| backdrop-filter: blur() | glass morphism은 AI 템플릿의 가장 흔한 징후 |
| gradient-text (배경 그라데이션 텍스트) | AI가 만든 SaaS 랜딩의 1번 특징 |
| "Powered by AI" 배지 | 기능이 아니라 장식. 사용자에게 가치 없음 |
| box-shadow 글로우 애니메이션 | 네온 글로우 = AI 슬롭 |
| 보라/인디고 브랜드 색상 | "AI = 보라색" 클리셰 |
| 모든 카드에 동일한 rounded-2xl | 균일한 둥근 모서리는 템플릿 느낌 |
| 배경 gradient orb (blur-3xl 원형) | 모든 AI 랜딩 페이지에 있는 장식 |
| Inter / Roboto / system-ui 본문 폰트 | 한글 렌더링이 나쁘고 어디서나 본 얼굴이 된다 |
| 크림색 배경 + 세리프 제목 + 테라코타 포인트 | 최근 생성 모델의 기본 하우스 스타일. 금융 도구와 결이 정반대 |

**리포트 블러 처리 주의**: `backdrop-filter`는 금지지만, 리포트 게이트의 블러는 텍스트 자체에 거는 `filter: blur(4px)` + `user-select: none`으로 구현한다. 배경 유리 효과가 아니라 콘텐츠 가리개다.

## 색상

### 배경
| 용도 | 값 |
|------|------|
| 페이지 | `#0b0b0d` |
| 카드 | `#141417` |
| 표 헤더 / 구분 배경 | `#1c1c20` |
| 보더 | `#2a2a30` |

### 텍스트
| 용도 | 값 |
|------|------|
| 주 텍스트 (숫자, 종목명) | `text-white` |
| 본문 | `text-neutral-300` |
| 보조 (레이블, 단위) | `text-neutral-400` |
| 비활성 / 데이터 없음 | `text-neutral-500` |

### 데이터/시맨틱 색상
| 용도 | 값 |
|------|------|
| 양수 / 성장 | `#22c55e` |
| 음수 / 감소 | `#ef4444` |
| 중립 / 기본 | `#525252` |

**채도 있는 색은 이 두 개(녹색·빨강)뿐이다.** 브랜드 포인트 색을 따로 두지 않는다 — 무채색 화면에서 색이 곧 의미가 되고, 데이터 이외의 것에 색을 쓰면 그 규칙이 깨진다.

유일한 예외는 **구글 로그인 버튼의 G 로고**다. 구글 브랜드 가이드가 로고 색 변경을 금지하므로 4색 원본을 그대로 쓴다. 대신 등장 위치를 로그인 버튼 하나로 묶어두면(로그인 화면 + 리포트 게이트), 데이터 화면의 "색 = 의미" 규칙은 그대로 유지된다.

주가를 다루지 않으므로 한국 증시의 "상승=빨강" 관례와 충돌하지 않는다. 여기서 녹색/빨강은 주가 등락이 아니라 **재무 수치의 증감**이며, 적자를 빨강으로 쓰는 국제 회계 관례를 따른다.

### 차트 계열 색
| 용도 | 값 |
|------|------|
| 검색한 종목 (기준선) | `#fafafa` — 굵기 2px |
| 관련주 | `#a3a3a3` → `#525252` 사이 명도 단계 — 굵기 1px |
| 그리드 / 축 | `#2a2a30` |
| 0% 기준선 | `#3f3f46` — 파선 |

관련주끼리 색으로 구분하지 않고 **명도로만 구분**한다. 8개 선에 8가지 색을 쓰면 무지개가 되고, 어느 선이 검색한 종목인지 순간적으로 알 수 없게 된다.

## 컴포넌트

### 카드
```
rounded-lg bg-[#141417] border border-[#2a2a30] p-5
```

### 버튼
```
Primary: rounded-lg bg-white text-black font-medium px-4 py-2.5 hover:bg-neutral-200
Ghost:   rounded-lg border border-[#2a2a30] text-neutral-300 px-4 py-2.5 hover:bg-[#1c1c20]
Text:    text-neutral-500 hover:text-neutral-300
```

### 구글 로그인 버튼

로그인 수단이 하나뿐이므로(ADR-014) 이 버튼이 곧 로그인 화면이다. Primary 버튼 위에 공식 G 로고를 얹는다.

```
rounded-lg bg-white text-black font-medium px-4 py-2.5 hover:bg-neutral-200
inline-flex items-center gap-2.5
로고: 공식 4색 G, 18px, 좌측 — 인라인 SVG, 색·비율 변경 금지
문구: "Google로 계속하기"
```

- **"또는", 구분선, 대체 로그인 링크를 두지 않는다.** 선택지가 하나뿐인데 선택지처럼 보이게 만들지 않는다.
- 리포트 게이트에서는 블러 처리된 본문 위 중앙에 이 버튼 하나와, 그 아래 `text-xs text-neutral-500`로 "로그인하면 전체 분석을 볼 수 있습니다" 한 줄만 둔다.
- 버튼을 **소셜 아이콘 원형 배지로 만들지 않는다.** 문구가 있는 가로형 버튼만 쓴다.

### 입력 필드 (검색창)
```
rounded-lg bg-[#141417] border border-[#2a2a30] px-4 py-3
focus: border-neutral-600 (링 없음)
```

### 데이터 테이블
```
헤더:  text-xs font-medium text-neutral-400 border-b border-[#2a2a30] py-2
셀:    text-sm text-neutral-200 tabular-nums py-2.5
행:    hover:bg-[#1c1c20]
기준행 (검색한 종목): bg-[#1c1c20] text-white font-medium — 항상 최상단 고정
```

**모든 숫자에 `tabular-nums`를 건다.** 자릿수가 흔들리면 비교표의 의미가 사라진다. 숫자는 우측 정렬, 텍스트는 좌측 정렬.

### 상관계수 배지
```
숫자:    text-sm tabular-nums (0.87 형식, 소수 둘째 자리)
표본 수: text-xs text-neutral-500 — "20분기" 형태로 항상 병기
표본 부족: "표본 부족" text-neutral-500, 수치 표시 안 함
```

### 데이터 없음
```
text-neutral-500 text-sm — "데이터 없음"
```
대시(—)나 0으로 대체하지 않는다. 0은 값이고, 없음은 값이 아니다.

## 레이아웃

- 전체 너비: `max-w-6xl` (비교표가 8행 × 10열이므로 5xl로는 좁다)
- 정렬: 좌측 정렬 기본. 중앙 정렬은 랜딩 히어로에서만 허용
- 간격: `gap-3~4`, 섹션 간 `space-y-8`
- 종목 상세 페이지 순서: 종목 헤더 → 관련주 + 비교표 → 성장률 차트 → 재무 5년 추이 → AI 리포트 게이트

## 타이포그래피

**본문 폰트: Pretendard.** 한글과 숫자가 같은 표에 섞이므로 한글 자족이 좋고 숫자 폭이 안정적인 서체를 쓴다. 숫자에는 `font-variant-numeric: tabular-nums`를 전역 적용한다.

| 용도 | 스타일 |
|------|--------|
| 페이지 제목 (종목명) | `text-3xl font-semibold text-white` |
| 티커 | `text-lg text-neutral-400 tabular-nums` |
| 섹션 제목 | `text-sm font-medium text-neutral-400 uppercase tracking-wide` |
| 카드 제목 | `text-sm font-medium text-neutral-300` |
| 본문 / 리포트 | `text-[15px] text-neutral-300 leading-relaxed` |
| 지표 수치 | `text-sm text-neutral-200 tabular-nums` |
| 캡션 / 출처 | `text-xs text-neutral-500` |

리포트 본문만 `text-[15px] leading-relaxed`로 읽기 밀도를 낮춘다. 긴 글이라 표와 같은 밀도로 두면 읽히지 않는다.

## 애니메이션

- `fade-in` (0.2s) — 페이지 진입, 리포트 로딩 완료
- 차트 선 그리기 (0.4s, ease-out) — 최초 렌더 1회만
- **그 외 모든 애니메이션 금지.** 호버 시 확대·이동·그림자 변화 없음. 색상 변화만 허용.

## 아이콘

- SVG 인라인, `strokeWidth 1.5`
- 아이콘 컨테이너(둥근 배경 박스)로 감싸지 않는다
- 아이콘은 기능이 있는 곳에만 — 검색, 외부 링크(EDGAR 원문), 툴팁 물음표. 장식용 아이콘 금지
- 예외: 구글 G 로고는 stroke가 아닌 fill 기반 4색 원본을 그대로 쓴다. 브랜드 가이드상 변형이 금지되어 있다

## 툴팁 (전문용어 설명)

PER·ROE·영업현금흐름 등 지표 레이블 옆에 물음표 아이콘을 두고, 호버/탭 시 1~2문장으로 설명한다.

```
트리거: text-neutral-500 hover:text-neutral-300, 12px 물음표 아이콘
본문:   rounded-md bg-[#1c1c20] border border-[#2a2a30] px-3 py-2 text-xs text-neutral-300 max-w-xs
```

설명은 정의만 쓰고 **좋다/나쁘다를 말하지 않는다.** "PER이 낮으면 저평가"류의 문장은 투자 판단이므로 ADR-012 위반이다.

## 면책 고지

모든 페이지 하단에 고정 표시한다.

```
text-xs text-neutral-500 border-t border-[#2a2a30] pt-4
```

문구: 본 서비스가 제공하는 정보는 투자 판단의 참고 자료이며 투자 자문이 아닙니다. 모든 데이터는 미국 증권거래위원회(SEC) 공시 자료를 기반으로 하며, AI가 생성한 분석은 오류를 포함할 수 있습니다. 투자의 최종 판단과 책임은 이용자 본인에게 있습니다.
