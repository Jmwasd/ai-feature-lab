# UI 디자인 가이드

토큰의 원본은 `docs/design/landing.html`이고, 구현 레시피는 `.claude/skills/peerlens-ui/SKILL.md`에 있다. 이 문서와 원본이 어긋나면 원본이 기준이다.

## 디자인 원칙

1. **도구처럼 보인다.** 화면의 주인공은 관련 근거와 숫자이며 장식은 없다.
2. **공개 정보부터 판단한다.** 첫 방문자는 로그인이나 블러 게이트 없이 종목의 관련주·공시 재무·실적일을 본다.
3. **한 화면에서 탐색을 이어 간다.** 검색 종목과 최대 5개 관련주를 비교하고, 관련주를 선택하면 같은 구조의 상세로 이동한다.
4. **모르는 것은 모른다고 쓴다.** 빈 데이터는 “데이터 없음”, 상관 표본이 부족하면 “표본 부족”으로 표시한다.

## 금지 사항

| 금지 사항 | 이유 |
|-----------|------|
| 글래스모피즘, 반투명 패널 위의 콘텐츠 | 데이터 도구에 불필요한 장식. `backdrop-filter`는 sticky nav 배경 한 곳에만 허용한다 |
| gradient-text, gradient orb, 글로우 애니메이션 | 정보 위계를 흐림 |
| 보라·인디고 브랜드 색상 | 색은 데이터 의미에만 사용 |
| 모든 요소에 `--r-lg`(16px) 적용 | 템플릿 같은 인상을 만듦 |
| 차트·카드·배지의 장식용 아이콘 | 초기 릴리스의 관련주 비교에 기여하지 않음 |
| 공개 정보의 로그인 CTA, 블러 게이트 | 관련주·재무·실적일의 열람 흐름을 끊음 |
| Tailwind 기본 팔레트(`neutral-*`, `gray-*`) | 아래 토큰과 회색 톤이 어긋남 |

## 색상

토큰 이름으로 참조한다. hex를 컴포넌트에 직접 쓰지 않는다.

### 표면과 선

| 토큰 | 값 | 용도 |
|------|-----|------|
| `--bg` | `#0b0d10` | 페이지 |
| `--surface` | `#14171c` | 카드, 검색창, 드롭다운, 타일 |
| `--surface-2` | `#191d23` | hover, 표 헤더, 기준행 |
| `--line` | `#242a31` | 기본 구분선, 카드 보더 |
| `--line-2` | `#2f363f` | 강조 보더 (입력창, 드롭다운, 칩) |

### 텍스트

| 토큰 | 값 | 용도 |
|------|-----|------|
| `--ink` | `#e8eaed` | 제목, 티커, 강조 수치 |
| `--body` | `#b4bac2` | 본문, 회사명, 근거 문장 |
| `--muted` | `#7c848e` | 라벨, 섹터, 기준일, 출처 |
| `--muted-soft` | `#565d66` | placeholder, 푸터, 비활성 |

### 의미색

| 토큰 | 값 | 용도 |
|------|-----|------|
| `--up` | `#3fb96b` | 재무 수치 증가 |
| `--down` | `#e5484d` | 재무 수치 감소 |
| `--accent` | `#c9ced6` | 포커스 보더 |

채도 있는 색은 녹색·빨강뿐이다. 이는 주가 등락이 아니라 재무 수치의 증감만 나타낸다. 라벨 없이 색만 있는 수치를 두지 않는다.

### 형태

```
--r-sm:6px    버튼, kbd, 배지
--r-md:10px   검색창, 드롭다운, 타일, 카드
--r-lg:16px   큰 컨테이너에만
```

## 컴포넌트

실제 마크업은 `docs/design/landing.html`에 있다. 새 값을 만들기 전에 해당 클래스를 먼저 확인한다.

### 검색창

```
height 54px, bg var(--surface), border 1px var(--line-2), radius var(--r-md)
focus-within: border-color var(--accent) (링 없음)
input font-size 16px
```

- 지원 50개 종목의 티커와 회사명만 자동완성한다.
- 자연어 질문·테마 키워드 입력을 받지 않는다.
- 결과가 없거나 지원하지 않는 티커를 입력하면 드롭다운 안에서 “현재는 지원 종목 50개만 검색할 수 있습니다”와 바로 고를 수 있는 칩을 표시한다. 빈 결과 페이지로 이동시키지 않는다.
- 자동완성 결과는 6개까지 노출하고 티커 접두사 일치를 앞에 정렬한다. 검색어 하이라이트는 배경 없이 `--ink` + `600`으로만 표시한다.

### 비교표

```
헤더:  mono 12px, color var(--muted), border-bottom 1px var(--line), py 9px
셀:    14px, color var(--body), tabular-nums, py 11px
행:    hover bg var(--surface-2)
기준행: bg var(--surface-2), color var(--ink), font-weight 500 — 항상 최상단
```

- 행은 검색 종목 1개와 관련주 최대 5개다.
- 수치는 최신 분기 매출, 매출 YoY, 최근 연간 영업현금흐름 세 열만 둔다.
- 모든 숫자는 mono + `tabular-nums`와 우측 정렬을 적용한다. 텍스트는 좌측 정렬한다.
- `0`이나 `—`로 결손을 감추지 않는다. 항상 “데이터 없음”을 쓴다.
- 관련주 티커·회사명 셀은 해당 종목 상세로 이동하는 링크다. 키보드 포커스와 링크임을 드러내되 장식용 아이콘은 붙이지 않는다.

### 관련성 표시

```
근거:     14px, color var(--body)
상관계수: mono 14px, tabular-nums (0.87 형식, 소수 둘째 자리)
표본 수:  12px, color var(--muted) — "20분기"
표본 부족: color var(--muted) — "표본 부족"
```

상관계수 옆에는 표본 수를 항상 병기한다. “검증됨”, “강력 추천”, “좋은 종목” 같은 평가 문구를 쓰지 않는다.

### 카드 · 타일

```
bg var(--surface), border 1px var(--line), radius var(--r-md), padding 13~20px
hover: border-color var(--line-2), bg var(--surface-2)
```

카드는 종목 헤더와 관련주 표처럼 정보 묶음이 있을 때만 사용한다. 모든 문장을 카드로 감싸지 않는다.

### 상태 배지

`확정`·`잠정`·`데이터 없음`·`예상`·`발표일 미정`·`재확인 중`은 항상 텍스트로 쓴다.

```
bg var(--surface-2), border 1px var(--line), radius var(--r-sm), 11~12px
```

### 재무제표·실적일

- 종목 상세의 재무제표에는 회계기간, `확정`·`잠정`·`데이터 없음` 상태, 공시 양식과 출처 링크를 수치 가까이에 둔다.
- 다음 실적 발표일에는 `확정`·`예상`·`발표일 미정`·`재확인 중` 상태, 출처와 마지막 확인 시각을 날짜와 함께 둔다. 과거 날짜를 다음 발표일처럼 보이게 하지 않는다.
- 상태 색상은 채도 있는 색만으로 전달하지 않는다. 상태 텍스트를 항상 함께 써서 색을 보지 못해도 이해할 수 있게 한다.

### AI 리포트

AI 리포트는 공개 상세를 가리는 게이트가 아니라, 재무제표·실적일 뒤에 놓는 별도 섹션이다.

- 비로그인 상태: 리포트 본문이나 흐린 미리보기를 보여 주지 않는다. `Google로 로그인하고 리포트 생성` CTA와, 현재 공시 기준으로 생성되며 한도가 적용될 수 있다는 설명만 표시한다.
- 로그인 상태·캐시 있음: 현재 `dataVersion`의 리포트를 바로 표시하고, 기준일·공시 출처·생성 시각을 상단에 둔다.
- 로그인 상태·캐시 없음: `AI 분석 리포트 생성` CTA를 표시한다. 생성 중에는 버튼을 중복 실행할 수 없게 하고 진행 상태를 텍스트로 알린다.
- 로그인 복귀: 로그인 전에 사용자가 생성 CTA를 누른 경우에만 리포트 패널을 열고 해당 요청을 재개한다. 링크 공유나 페이지 새로고침만으로 생성하지 않는다.
- 실패·한도 초과·설정 미완료: 공개 상세는 그대로 유지하고, 리포트 패널 안에서 이유와 가능한 다음 행동(재시도 또는 나중에 다시 시도)을 표시한다.

## 레이아웃

- 페이지 컨테이너: `max-width 760px`, 좌우 `padding 24px`
- 검색·결과 블록: `max-width 600px`
- nav: 높이 `56px`, `border-bottom 1px var(--line)`, sticky
- 좌측 정렬 기본. 랜딩 히어로만 중앙 정렬을 허용한다.
- 간격: 요소 간 `10~16px`, 섹션 간 `40~56px`
- 종목 상세 순서: 종목 헤더(기준일 포함) → 관련주 근거·상관 표시 → 3개 지표 비교표 → 재무제표 → 다음 실적 발표일 → AI 리포트(선택) → 데이터 한계 및 면책 고지
- 5년 추이와 성장률 차트는 만들지 않는다. AI 리포트는 위의 선택 섹션 외에 랜딩이나 공개 데이터 영역에 끼워 넣지 않는다.

## 타이포그래피

본문은 Inter, 숫자와 티커는 mono를 쓴다.

```
--sans: Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif
--mono: ui-monospace, "SF Mono", Menlo, Consolas, monospace
```

기준은 `14px / 1.5`. 모든 숫자에 `font-variant-numeric: tabular-nums`를 적용한다.

| 용도 | 스타일 |
|------|--------|
| 히어로 제목 | `34px / 1.15`, `-.02em`, `600`, `--ink` |
| 히어로 설명 | `15px`, `--body`, `max-width 520px` |
| eyebrow / 섹션 라벨 | mono `12px`, `letter-spacing .16em`(섹션 `.08em`), uppercase, `--muted` |
| 본문 / 근거 | `14px`, `--body` |
| 티커 | mono `14px`, `600` |
| 지표 수치 | mono `13~14px`, `tabular-nums` |
| 기준일 / 출처 / 섹터 | `12~13px`, `--muted` |
| 푸터 | `12px / 1.7`, `--muted-soft` |

긴 한국어 문장에는 `text-wrap: pretty`를 적용한다.

## 애니메이션과 아이콘

- 페이지 진입에 `fade-in` 0.2초만 허용한다.
- `transition`은 `border-color`, `background`에 `.15s`까지만 건다.
- 호버 확대·이동·그림자 변화, 차트 선 그리기, 로딩 장식은 만들지 않는다.
- SVG 아이콘은 검색·외부 SEC 링크·안내처럼 기능이 있을 때만 사용한다. `stroke-width`는 2, 크기는 15~18px다.

## 툴팁

전문 용어에만 물음표 아이콘을 둔다. 대상은 매출 성장률, 영업현금흐름, 상관계수, `잠정` 상태다.

```
트리거: color var(--muted), hover var(--body), 12px 물음표 아이콘
본문:   bg var(--surface-2), border 1px var(--line), radius var(--r-sm), padding 8px 12px, 12px, max-width 320px
```

설명은 정의만 쓰며 투자 판단을 유도하지 않는다. 툴팁은 CSS hover·focus만으로 표시하고 Client Component를 만들지 않는다. 허용된 Client Component는 검색 자동완성과 AI 리포트 패널뿐이다.

## 면책 고지

모든 페이지 하단에 표시한다.

```
12px / 1.7, color var(--muted-soft), border-top 1px var(--line), padding-top 24px
```

문구: 본 서비스가 제공하는 정보는 공개 공시 자료와 자동 생성된 관련성 정보를 정리한 참고 자료이며 투자 자문이 아닙니다. 자동 생성 결과와 공시 데이터에는 오류 또는 누락이 있을 수 있습니다. 투자의 최종 판단과 책임은 이용자 본인에게 있습니다.
