# PRD: PeerLens

## 목표

초기 지원하는 S&P 500 종목 50개 중 하나를 검색하면, 종목 상세에서 다음 정보를 제공한다.

1. 관련주 최대 5개와 사업상 관련 근거·분기 매출 성장률 상관 지표
2. 최신 공시 기준 재무제표 요약
3. 다음 실적 발표일과 확정/예상 상태
4. Google 로그인 사용자만 열람할 수 있는 AI 분석 리포트

재무제표와 다음 실적 발표일은 공개한다. AI 리포트는 사용자가 버튼을 누른 경우에만 Google 로그인과 서버 측 AI 생성을 거쳐 보여준다.

## 사용자

미국 주식에 투자하는 한국 개인투자자(서학개미) 중 종목 발굴과 공시 확인 시간을 줄이고 싶은 중급자.

- 영문 사업 설명과 관련주 근거를 빠르게 이해하고 싶은 사람
- 최신 실적 수치·다음 실적 발표 시점을 한 화면에서 확인하고 싶은 사람
- AI가 어떤 공시 기준으로 분석했는지 직접 확인하고 싶은 사람
- 수치가 없거나 잠정치·표본이 부족할 때 그 사실을 명확히 보려는 사람

## 성공 기준

- 지원 종목 검색 후 공개 정보(관련주·재무제표·실적일)를 한 화면에서 확인할 수 있다.
- 관련주를 선택하면 해당 종목의 공개 상세로 이동해, 탐색 흐름이 끊기지 않는다.
- 지원하지 않는 티커 또는 검색 결과가 없는 입력에는 그 이유와 지원 범위를 보여 주며 빈 화면으로 끝나지 않는다.
- 모든 재무 수치에는 회계기간, 데이터 기준일, 출처와 `확정`·`잠정`·`데이터 없음` 상태가 있다.
- 다음 실적 발표일에는 출처와 `확정`·`예상`·`미정`·`재확인 중` 상태가 있다.
- 비로그인 사용자는 리포트 본문을 볼 수 없고, 로그인 후 원래 종목으로 돌아와 리포트를 열 수 있다.
- AI 리포트는 현재 재무 스냅샷 버전에 연결되어 오래된 데이터를 최신 분석처럼 표시하지 않는다.

## 사용자 여정 우선순위

1. **먼저 공개 정보를 확인한다.** 첫 방문자는 계정 생성, 권한 요청, 외부 API 대기 없이 종목의 관련주·핵심 재무·다음 실적일을 본다.
2. **탐색을 이어 간다.** 관련주 행을 선택하면 같은 정보 구조의 해당 종목 상세로 이동한다. 지원 범위 밖 종목을 입력했을 때도 지원 범위와 다음 행동을 안내한다.
3. **출처와 한계를 판단한다.** 숫자 옆의 기간·상태·출처를 통해 최신성 및 결손을 스스로 확인한다. 모르는 값을 추정해 빈칸을 감추지 않는다.
4. **AI 분석은 선택적으로 요청한다.** 공개 정보를 본 뒤에만 별도 CTA로 리포트를 생성한다. 로그인과 한도 때문에 핵심 탐색 흐름을 막거나 흐리게 하지 않는다.

## 핵심 기능

1. **종목 검색** — 초기 지원 50개 종목의 티커/회사명 자동완성.
2. **관련주 최대 5개 제시** — 사업 관계 근거 한 줄, 분기 매출 성장률 상관계수, 표본 수를 함께 표시. 후보가 품질 기준을 충족하지 않으면 5개를 억지로 채우지 않는다.
3. **재무제표** — 기본적으로 최신 분기 매출, 매출 YoY 성장률, 최근 연간 영업현금흐름을 표시한다. 확장 표는 손익계산서(매출·영업이익·순이익), 재무상태표(현금·총자산·총부채·자본), 현금흐름표(영업·투자·재무활동 현금흐름)를 제공한다.
4. **다음 실적 발표일** — 날짜, 시간대가 있으면 시간대, `확정` 또는 `예상` 상태, 출처와 마지막 확인 시각을 표시한다. 확인할 수 없으면 날짜를 추정하지 않고 `발표일 미정`으로 표시한다.
5. **AI 분석 리포트** — 공개 정보 뒤의 별도 섹션에서 연다. 비로그인 사용자는 현재 종목과 스냅샷에 대한 생성 의도를 보존한 채 Google 로그인으로 이동하며, 로그인 사용자는 현재 데이터 버전의 리포트를 생성하거나 기존 리포트를 조회한다. 생성 CTA에는 한도 소모 가능성을 미리 알린다.
6. **데이터 한계 표시** — XBRL 값이 없으면 “데이터 없음”, 상관계수 공통 표본이 8분기 미만이면 “표본 부족”, 잠정 실적이면 “10-Q/10-K 공시 후 확정”을 표시한다.

상관계수는 매출 성장의 동행 정도를 보여 주는 보조 지표다. AI 리포트와 모든 화면에서 사업 관계의 인과, 매수·매도 의견, 목표가, 수익 보장을 표현하지 않는다.

## 사용자 흐름

```
랜딩 → 티커/회사명 검색
          ├─ 지원 종목 선택 → /s/[ticker] 종목 상세
          │                    ├─ 관련주·재무제표·다음 실적 발표일 (공개)
          │                    │     └─ 관련주 선택 → 해당 /s/[peerTicker] 상세
          │                    └─ AI 분석 리포트 (선택)
          │                         ├─ 비로그인 → Google 로그인 → 원래 상세·리포트 패널로 복귀
          │                         │                              → 의도한 생성 요청만 재개
          │                         └─ 로그인됨 → 캐시 조회 또는 생성 → 리포트 패널 표시
          └─ 결과 없음/미지원 티커 → 지원 범위 안내 → 다시 검색
```

검색과 공개 상세 화면은 사전 생성된 스냅샷만 읽는다. SEC, 실적 일정 제공자, AI 제공자를 브라우저나 검색 요청 경로에서 호출하지 않는다.

로그인 후의 자동 재개는 로그인 전에 사용자가 명시적으로 `리포트 생성`을 선택한 경우에만 허용한다. 단순한 URL 파라미터나 상세 페이지 재방문만으로 새 AI 호출을 시작하지 않는다. 이미 생성된 현재 버전의 리포트는 로그인 후 즉시 조회할 수 있다.

## 데이터와 갱신

### 재무제표

- `확정` 값은 10-Q 또는 10-K의 XBRL에서 수집한다.
- 실적 발표 직후 8-K Item 2.02 보도자료에서 검증 가능한 분기 매출만 `잠정`으로 표시할 수 있다. 잠정 수치는 확정 수치를 덮어쓰지 않는다.
- 새 10-Q/10-K가 들어오면 해당 종목의 재무 스냅샷을 확정값으로 갱신하고, 해당 종목과 관련주 쌍의 상관계수를 다시 계산한다.
- 실패한 갱신은 배포하지 않고 마지막 정상 스냅샷을 유지한다.

### 다음 실적 발표일

SEC는 이미 발생한 공시를 제공하므로, 미래 실적일은 별도 일정 출처가 필요하다. 기업 IR 페이지에 명시된 날짜를 우선해 `확정`으로 표시하고, 계약한 일정 제공자의 날짜는 `예상`으로 표시한다. 두 출처가 없거나 충돌하면 `발표일 미정`으로 둔다.

### AI 리포트

- 리포트 입력은 현재 종목의 **확정** 재무 스냅샷, 사업 설명, 관련주 근거, 출처와 데이터 기준일이다.
- AI 제공자는 OpenAI Responses API의 `gpt-5.6-terra`를 사용한다. 초기 버전에서는 웹 검색·파일 검색 등 외부 도구를 켜지 않고, 사용자가 보고 있는 `market-data.json`의 동일 `dataVersion` 검증 데이터만 서버에서 입력으로 사용한다.
- 동일한 `ticker + dataVersion + promptVersion` 조합은 재사용한다.
- 새 확정 스냅샷이 배포되면 이전 버전 리포트는 현재 리포트로 반환하지 않고, 새 버전의 생성 CTA를 표시한다.
- AI 호출 실패 결과는 캐시하지 않으며, 사용자에게 재시도 가능 상태를 보여준다.

## 인증·비용·보안

- Google OAuth는 AI 리포트 생성·조회에만 사용한다. 재무제표와 실적일에 로그인 장벽을 두지 않는다.
- 리포트 API는 어떤 캐시 조회나 본문 반환보다 먼저 서버에서 세션을 검증한다.
- OpenAI API 키, SEC 접근용 User-Agent, 일정 제공자 키는 서버 또는 갱신 작업의 비밀 변수로만 보관한다.
- 사용자별·전역 생성 한도를 원자적으로 예약하고, AI 호출 실패 시 예약을 취소한다.
- 인증 세션, 리포트 캐시, 한도 기록은 정적 JSON과 분리된 서버 저장소에서 관리한다. 재무 스냅샷은 정적 파일로 유지한다.

## 제외 사항

- **S&P 500 전체 커버리지** — 초기 50개 종목의 품질·운영 비용을 검증한 뒤 확대한다.
- **주가·시세 데이터 일체** — 주가 차트, 실시간/지연 시세, 주가 상관계수.
- **모든 종목쌍 상관계수 사전 계산** — LLM 후보 종목쌍만 계산한다.
- **결제·구독, 개별 투자 상담, 매수·매도 추천, 목표가**.
- **한국 주식, S&P 500 외 미국 종목, 뉴스 요약, 자연어 종목 검색**.

## 구현 전 필요한 외부 결정

| 항목 | 필요한 결정 |
| --- | --- |
| 재무제표 범위 | 기본 3개 지표 외에 각 표·기간을 어디까지 제공할지 |
| 실적 발표일 | 계약할 일정 제공자, IR 수집 정책 또는 수동 관리 방식 |
| Google OAuth | Google Cloud 프로젝트, 승인된 리디렉션 URL과 배포 도메인 |
| AI | OpenAI `gpt-5.6-terra`의 월 예산·사용자별 일일 생성 한도 |
| 저장소 | 인증 세션·리포트 캐시·사용량 기록의 보존 기간과 저장소 |
| 잠정치 | 8-K 수치를 재무 화면·AI 리포트에 허용할 정확한 범위 |

## 디자인

- 다크모드 고정, 데이터 밀도 우선, 무채색 기반.
- 양수/성장은 녹색, 음수/감소는 빨강으로만 표시한다.
- 상관계수와 표본 수, 재무 데이터 기준일, 실적일의 상태·출처를 항상 같이 보여 준다.
- AI 리포트에는 기준일, 공시 출처, 투자 참고 자료라는 면책 문구를 항상 표시한다.
- 상세 규칙은 `UI_GUIDE.md`를 따른다.

## 법적 포지셔닝

- 서비스는 공개 공시 데이터와 자동 생성된 관련성·분석을 정리한 정보 제공 화면이다.
- 매수·매도 의견, 목표가, 수익 보장을 제시하지 않는다.
- 면책 문구는 제공하되, 그것만으로 법적 의무가 사라진다고 단정하지 않는다.
- 실적 일정 제공자 계약, AI 리포트, 유료화·개별 상담을 도입하기 전에는 해당 시점의 규제·데이터 라이선스·이용 조건을 별도로 검토한다.
