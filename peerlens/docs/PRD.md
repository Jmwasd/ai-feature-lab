# PRD: PeerLens

## 목표

미국 주식 티커 하나를 검색하면, 그 종목과 관련된 종목 8개를 **"왜 관련 있는지"의 근거와 검증 가능한 숫자까지 붙여** 한국어로 보여준다.

## 사용자

미국 주식에 투자하는 한국 개인투자자(서학개미) 중 **중급자**.

- PER·ROE 같은 지표는 이미 알고 있고, 종목 발굴에 드는 시간을 아끼고 싶은 사람
- 영문 자료 장벽 때문에 한국어로 정리된 정보를 찾는 사람
- 입문자도 읽을 수 있도록 전문용어에는 툴팁으로 설명을 붙인다 (단, 화면을 입문자 기준으로 쉽게 만들지는 않는다)

## 성공 기준

**배포 후 이메일 가입 30명.**

가입은 AI 리포트를 보려는 사람만 하므로, 가입자 수 = "이 서비스에 값을 치를 의사가 있는 사람 수"의 대리 지표다. 결제를 붙이지 않기로 했으므로 이 숫자가 유일한 수요 검증 신호다.

가입 수단은 **구글 로그인 하나뿐**이므로(ADR-014), 여기서 세는 이메일 주소는 전부 구글이 검증한 실주소다. 오타·일회용 주소가 섞이지 않아 지표를 그대로 신뢰할 수 있다.

## 핵심 기능

1. **종목 검색** — S&P 500 종목의 티커/회사명 자동완성. 입력 모호성 없이 종목을 확정시킨다.
2. **관련주 8개 제시** — 각 종목마다 관련성 근거 한 줄 + 분기 매출 성장률 상관계수 + **표본 수**를 함께 표시.
3. **재무 요약** — 핵심 지표 8~10개와 5년 추이. 검색종목과 관련주 8개를 한 표에 나란히 비교.
4. **분기 매출 성장률 오버레이 차트** — 검색종목과 관련주의 분기 성장률을 한 차트에 겹쳐, 상관계수 숫자를 눈으로 확인할 수 있게 한다.
5. **AI 심층 분석 리포트** — 개별 종목의 10-K 핵심 섹션(Item 1 사업, Item 1A 리스크, Item 7 MD&A)을 근거로 한 한국어 분석. **로그인 필요**, 첫 문단만 미리보기 후 나머지는 블러.
6. **구글 로그인** — 로그인 수단은 구글 계정 하나뿐이다. 블러 아래의 "Google로 계속하기" 버튼에서 시작해, 인증이 끝나면 **읽던 종목 페이지의 리포트 위치로 그대로 되돌아온다.** 별도의 가입 폼도, 비밀번호도, 메일함 확인도 없다.

## 사용자 흐름

```
랜딩 → 검색 → 종목 상세(관련주 + 재무 + 차트, 전면 공개)
                    ↓ 관련주 클릭
              해당 종목 상세
                    ↓ "AI 심층 분석 보기"
        리포트 첫 문단 미리보기 + 블러
                    ↓ "Google로 계속하기"
        구글 동의 화면 → 원래 보던 종목 페이지로 복귀 → 전체 리포트
```

관련주 발굴이 리포트 소비의 진입 경로가 되도록 설계한다. 리포트는 유일한 가입 트리거이므로, 이 동선이 곧 성공 지표다.

로그인은 이 흐름에서 **유일한 이탈 구간**이다. 그래서 별도 가입 페이지로 보내지 않고, 리포트를 읽던 자리에서 구글 버튼 하나로 끝낸 뒤 같은 자리로 돌려보낸다(ADR-014).

## MVP 제외 사항

- **주가·시세 데이터 일체** — 주가 차트, 실시간/지연 시세, 주가 상관계수. 무료 시세 API는 웹 표시(재배포)를 약관으로 금지한다.
- **결제·구독** — 플랜, 결제 연동, 구독 스키마를 **코드에 남기지 않는다.** 나중에 붙일 때의 비용보다 지금 남겨두는 죽은 코드의 비용이 크다.
- **테마 키워드 검색**("HBM", "전력망")과 **자연어 질문** — 결과가 이상할 때 키워드 매핑이 틀린 건지 관련주 로직이 틀린 건지 구분할 수 없게 된다.
- **한국 주식, S&P 500 외 미국 종목** — 데이터 파이프라인이 두 벌이 된다.
- **뉴스·실적발표 요약** — 매일 재생성되므로 캐시가 불가능해 비용이 사용자 수에 비례한다.
- **라이트모드, 테마 토글** — 모든 차트·표·배경 색을 두 벌로 검증해야 한다.
- **구글 외 로그인 수단** — 이메일+비밀번호, 매직링크, 그 외 소셜(GitHub·Apple 등). 수단마다 인증 경로와 실패 모드가 한 벌씩 늘어난다. 근거는 ADR-014.
- **프로필·마이페이지·조회 이력** — 로그인은 리포트 열람 권한과 사용량 카운터에만 쓴다. 사용자가 관리할 계정 정보 자체가 없다.
- **봇 방어, 이메일 도메인 차단** — 전역 일일 상한이 최종 방어선이므로 계정을 여러 개 만들어도 지출은 늘지 않는다.
- **3대 재무제표 전문** — XBRL 계정과목 정규화가 지옥이고 중급자에게도 과잉이다.

## 디자인

- **다크모드 고정.** 데이터 밀도 높게. 마케팅 페이지가 아니라 매일 쓰는 도구처럼 보여야 한다.
- **무채색 기반 + 채도 있는 색은 두 개뿐** — 양수(녹색), 음수(빨강). 주가를 다루지 않으므로 한국 증시의 상승=빨강 관례와 충돌하지 않고, 재무 수치의 국제 회계 관례(적자=빨강)를 따른다.
- 상세 규칙은 `UI_GUIDE.md`.

## 제약

| 항목 | 값 |
|------|-----|
| 인원 | 1명 |
| 기간 | 3~4주 |
| 인프라 비용 | $0 (Vercel Hobby + Supabase 무료 티어) |
| LLM 비용 상한 | 월 최대 $150 (리포트 전역 20건/일 × $0.25) |
| 데이터 비용 | $0 (SEC EDGAR만 사용) |

결제 구현이 스코프에서 빠지며 확보된 1~1.5주는 **전부 관련주 품질**(프롬프트 반복 개선, 환각 필터 강화, 상관계수 산출 검증, 결과 수동 검수)에 투입한다. 이것이 이 제품의 유일한 차별점이고, 여기서 실패하면 나머지가 전부 무의미해진다.

## 법적 포지셔닝

- **정보 제공 서비스**로 포지셔닝한다. 투자자문이 아니다.
- AI 출력은 데이터 요약·비교로 한정하고, **매수/매도 의견과 목표가 제시를 프롬프트 레벨에서 금지**한다.
- 전 페이지 하단과 이용약관에 면책 문구를 명시한다.
- 전면 무료이므로 "대가를 받고 투자판단을 조력"하는 구조가 아니며, 유사투자자문업 신고 대상이 되지 않는다. **결제를 도입하는 순간 이 전제가 깨진다.**

## 알려진 리스크

1. **전역 상한과 성공 지표의 충돌** — 하루 20건이 소진되면 그날 신규 방문자는 리포트를 볼 수 없고, 리포트가 유일한 가입 트리거이므로 그날의 가입 전환이 막힌다. 유입이 몰리는 날일수록 정확히 그 순간에 막힌다. 완화책: 상한 도달 후에도 **이미 캐시된 종목의 리포트는 그대로 열람 가능**하게 한다(신규 생성만 차단).
2. **EDGAR XBRL 계정과목 정규화** — 회사마다 태그가 달라 지표 누락이 실제로 자주 발생한다. 지표를 10개로 제한해 완화했으나 실제 커버리지는 붙여봐야 안다.
3. **분기 매출 상관계수의 통계적 취약성** — 5년치라도 분기는 20개뿐이다. 표본 수를 항상 함께 노출해 정직성을 확보하되, 수치의 신뢰도가 낮다는 사실을 UI에서 숨기지 않는다.
