# PeerLens UI

## 이 스킬의 역할

PeerLens 화면은 **공시 데이터를 판단하게 하는 도구**다. 장식이 정보 위계를 흐리면 안 되고, 숫자는 항상 "언제 기준의, 무엇의, 어떤 상태인" 값인지 함께 보여야 한다. 이 스킬은 그 두 가지를 지키는 토큰과 레시피를 담는다.

구현 원본은 `docs/design/landing.html`이다. 새 화면을 만들기 전에 그 파일에서 가장 가까운 패턴을 찾아 재사용하라. 값을 새로 만드는 것보다 항상 낫다.

## 토큰

원본은 CSS 변수로 정의돼 있다. 앱에서는 `globals.css`에 같은 이름으로 선언하고 Tailwind에서 참조한다. **하드코딩한 hex나 Tailwind 기본 팔레트(`neutral-300`, `gray-800` 등)를 쓰지 마라.** 두 계열이 섞이면 화면마다 회색 톤이 미묘하게 달라진다 — PeerLens의 중립색은 파란기가 도는 램프라 Tailwind 기본 neutral과 겹치지 않는다.

### 표면과 선

| 변수 | 값 | 용도 |
|------|-----|------|
| `--bg` | `#0b0d10` | 페이지 배경 |
| `--surface` | `#14171c` | 카드, 검색창, 드롭다운, 타일 |
| `--surface-2` | `#191d23` | hover, 표 헤더, 기준행 |
| `--line` | `#242a31` | 기본 구분선, 카드 보더 |
| `--line-2` | `#2f363f` | 강조 보더 (입력창, 드롭다운, 칩) |

### 텍스트

| 변수 | 값 | 용도 |
|------|-----|------|
| `--ink` | `#e8eaed` | 제목, 티커, 강조 수치 |
| `--body` | `#b4bac2` | 본문, 회사명, 근거 문장 |
| `--muted` | `#7c848e` | 라벨, 섹터, 기준일, 출처 |
| `--muted-soft` | `#565d66` | placeholder, 푸터, 비활성 |

### 의미색

| 변수 | 값 | 용도 |
|------|-----|------|
| `--up` | `#3fb96b` | 재무 수치 증가 |
| `--down` | `#e5484d` | 재무 수치 감소 |
| `--accent` | `#c9ced6` | 포커스 보더 |

채도 있는 색은 이 셋뿐이다. 브랜드 색으로 쓰지 마라. 초록/빨강은 **재무 수치의 증감**만 뜻하며 주가 등락이 아니다 — 이유는 아래 "숫자 표시 규칙"에 있다.

### 형태와 서체

```css
--r-sm:6px;   /* 버튼, kbd, 작은 배지 */
--r-md:10px;  /* 검색창, 드롭다운, 타일, 카드 */
--r-lg:16px;  /* 큰 컨테이너에만. 남용하면 템플릿처럼 보인다 */
--mono: ui-monospace,"SF Mono",Menlo,Consolas,monospace;
--sans: Inter,-apple-system,BlinkMacSystemFont,"Segoe UI",Roboto,sans-serif;
```

본문 기준은 `14px / line-height 1.5`, `-webkit-font-smoothing:antialiased`.

**티커와 모든 숫자는 mono + `tabular-nums`다.** 자릿수가 흔들리면 표에서 값을 세로로 비교할 수 없다. 원본의 `.mono` 클래스가 이 둘을 함께 건다.

## 타이포 스케일

| 용도 | 스타일 |
|------|--------|
| 히어로 제목 | `34px / 1.15`, `-.02em`, `600`, `--ink` |
| 히어로 설명 | `15px`, `--body`, `max-width:520px` |
| eyebrow / 섹션 라벨 | mono `12px`, `letter-spacing:.16em`(섹션은 `.08em`), uppercase, `--muted` |
| 본문 | `14px`, `--body` |
| 티커 | mono `14px`, `600` |
| 보조 (섹터, 기준일, 출처) | `12~13px`, `--muted` |
| 푸터 | `12px / 1.7`, `--muted-soft` |

긴 한국어 문장에는 `text-wrap:pretty`를 건다. 조사 하나가 홀로 줄바꿈되는 걸 막아준다.

## 레이아웃

- 페이지 컨테이너 `max-width:760px`, 좌우 `padding:24px`
- 검색·결과 블록 `max-width:600px`
- nav 높이 `56px`, `border-bottom:1px solid var(--line)`, sticky
- 랜딩 히어로 `padding:88px 0 40px`, 중앙 정렬
- **중앙 정렬은 랜딩 히어로에서만.** 상세 페이지는 좌측 정렬이다. 데이터를 읽는 화면에서 중앙 정렬은 눈의 시작점을 매번 옮기게 만든다.

## 컴포넌트 레시피

전부 `docs/design/landing.html`에 실제 마크업이 있다. 아래는 핵심 규칙만 요약한 것이니, 만들기 전에 원본의 해당 클래스를 열어보라.

### 검색창 (`.search-box`)

높이 `54px`, `--surface` 배경, `--line-2` 보더, `--r-md`. 포커스는 `:focus-within`으로 보더만 `--accent`로 바꾼다 — **ring이나 글로우를 쓰지 마라.** 왼쪽에 검색 아이콘, 오른쪽에 `/` 단축키 힌트(`.kbd`, mono 11px)를 둔다. 입력 폰트는 `16px`(모바일 자동 확대 방지).

### 자동완성 드롭다운 (`.dd`)

`position:absolute; top:60px`, `--surface`, `--line-2` 보더, `--r-md`, `overflow:hidden`.

- 헤더(`.dd-head`): 좌측 "지원 종목 N개", 우측 "티커 · 회사명". mono 12px, `--muted`
- 행(`.opt`): 티커(mono 600, 고정폭 64px) → 회사명(`--body`, ellipsis) → 섹터(12px, `--muted`)
- 검색어 하이라이트는 `<mark>`에 `background:transparent; color:var(--ink); font-weight:600` — 형광펜 배경을 쓰지 마라
- 키보드: ↑↓ 이동, Enter 이동, Esc 닫기. hover와 키보드 active가 같은 `--surface-2`를 쓴다
- 최대 6개까지만 노출하고, 티커 접두사 일치를 앞으로 정렬한다

### 결과 없음 (`.empty`)

빈 화면으로 보내지 마라. 드롭다운 안에서 처리한다.

1. 굵게(`--ink`): `"{입력값}" 은(는) 지원 범위에 없어요.`
2. 힌트(`--muted` 13px): 현재 지원 범위 설명
3. 칩(`.chip`, pill, mono 12px): 바로 고를 수 있는 종목들

### 종목 타일 (`.tile`)

`--surface` 배경, `--line` 보더, `--r-md`, `padding:13px 15px`. hover에서 보더 `--line-2` + 배경 `--surface-2`로만 바뀐다. 2열 그리드, `gap:10px`.

### 상태 배지

`확정` / `잠정` / `데이터 없음` / `예상` / `발표일 미정` / `재확인 중`은 **항상 텍스트로 쓴다.** 색만으로 상태를 전달하면 색을 구분하지 못하는 사용자에게 정보가 사라진다. 배지는 `--surface-2` 배경에 `--line` 보더, `--r-sm`, 11~12px.

### 애니메이션

`transition`은 `border-color`와 `background`에 `.15s`까지만. 페이지 진입 `fade-in` 0.2초는 허용한다. 확대·이동·그림자 변화·차트 그리기·로딩 장식은 만들지 마라.

### 아이콘

기능이 있을 때만 쓴다 (검색, 외부 SEC 링크, 안내). `stroke-width:2`, `15~18px`, `currentColor`. 카드·배지·표에 장식용 아이콘을 붙이지 마라.

## 숫자 표시 규칙

디자인보다 우선한다. 여기를 틀리면 화면이 예뻐도 제품이 틀린다.

**1. 채도 있는 숫자에는 무엇의 증감인지 라벨을 붙여라.**
초록색 `+69.2%`가 라벨 없이 티커 옆에 있으면 누구나 주가 등락으로 읽는다. PeerLens는 주가를 다루지 않으므로(ADR-002) 이건 사실이 아닌 인상을 준다. `매출 YoY +69.2%`처럼 지표명을 함께 쓰거나, 열 헤더가 지표를 명시한 표 안에서만 라벨을 생략하라.

**2. 없는 값은 "데이터 없음"이라고 써라.**
`0`, `—`, `N/A`로 채우지 마라. 대체 XBRL 태그로 추론해 메우는 것도 금지다. 결손을 감추면 사용자가 그 값을 실제 수치로 믿는다.

**3. 모든 수치에 회계기간·기준일·출처·상태를 붙여라.**
숫자 가까이에 둔다. 표에서는 열 또는 행 단위로 한 번만 보여도 된다.

**4. 상관계수에는 표본 수를 항상 병기하라.**
`0.87 · 20분기` 형식. 공통 표본이 8분기 미만이면 수치를 숨기고 `표본 부족`으로 쓴다.

**5. 관련주는 최대 5개다.**
품질 기준을 못 채우면 빈자리를 채우지 말고 부족한 상태를 보여준다.

**6. 평가·투자 판단 표현을 쓰지 마라.**
`검증됨`, `강력 추천`, `좋은 종목`, 목표가, 매수·매도 의견 전부 금지다. 관련성은 사업 관계의 설명이지 투자 판단이 아니다.

## 공개 화면과 로그인

재무제표·실적일·관련주는 **로그인 없이 전부 보인다.** 공개 정보 위에 로그인 CTA나 블러 미리보기를 얹지 마라 — 첫 방문자가 판단을 끝내는 게 이 제품의 첫 우선순위다(ADR-007).

로그인 요소는 두 곳에만 둔다: nav의 로그인 버튼, 그리고 재무제표·실적일 **뒤에** 놓는 AI 리포트 섹션. 비로그인 상태의 리포트 섹션은 본문도 흐린 미리보기도 보여주지 않고, CTA와 "현재 공시 기준으로 생성되며 한도가 적용될 수 있다"는 설명만 표시한다.

## 하지 말 것

| 금지 | 이유 |
|------|------|
| `backdrop-filter`, 글래스모피즘 | 데이터 위에 얹는 장식. 원본 nav에 남아 있지만 확산시키지 마라 |
| 그라데이션 텍스트, glow, orb | 정보 위계를 흐림 |
| 보라·인디고 브랜드 색 | 색은 데이터 의미에만 |
| 모든 요소에 `--r-lg` | 템플릿 같은 인상 |
| Tailwind 기본 팔레트 | 위 토큰과 회색 톤이 어긋남 |
| 5년 추이 차트, 성장률 다중선 차트 | 초기 릴리스 범위 밖 |
| 숫자에 `tabular-nums` 누락 | 세로 비교가 깨짐 |

## Client Component 경계

Server Component가 기본이다. Client Component는 **검색 자동완성**과 **AI 리포트 패널(인증·생성 상태)** 둘뿐이다. 툴팁은 CSS `hover`/`focus`로 만들고 상태를 만들지 마라.

## 데이터 출처

화면에 들어가는 값은 전부 `src/data/market-data.json` 스냅샷에서 온다. `docs/design/landing.html`의 `TICKERS` 배열은 디자인 시안용 하드코딩이므로 그대로 옮기지 마라. 검색 경로에서 SEC·일정 제공자·LLM을 호출하지 않는다.
