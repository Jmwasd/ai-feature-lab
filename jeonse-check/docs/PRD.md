# PRD: jeonse-check

## 목표
주소와 보증금만 넣으면 공공데이터로 전세가율과 건물 위험 신호를 자동으로 판정하고, 사용자가 등기부를 보고 입력한 권리관계를 합쳐 부채비율과 HUG 전세보증보험 가입 가능 여부까지 보여준다.

## 사용자
전세 계약을 앞둔 임차인. 특히 시세를 확인하기 어려운 연립·다세대(빌라) 계약자.

## 사용자 흐름
랜딩 페이지 → Google OAuth 로그인 → 서비스(조회·판정·결과 저장)

## 핵심 기능
1. **시세 쪽 자동 판정** — 주소·보증금·전용면적을 입력하면 국토부 실거래가·공시가격·건축물대장으로 전세가율을 계산하고, 건축물대장의 용도·위반건축물 여부·사용승인일에서 건물 위험 신호를 찾는다. 시세 추정에는 근거(비교 거래 목록)와 신뢰도를 함께 표시한다.
2. **권리 쪽 수동 입력** — 등기부 권리관계는 공개 API가 없으므로 사용자가 등기부를 보고 근저당 채권최고액, 신탁 여부, 최근 소유자 변동을 입력한다.
3. **종합 판정** — 두 축을 합쳐 부채비율과 HUG 보증보험 가입 가능 여부(공시가격×126% 기준 등)를 계산하고, 결과를 "위험 신호 N개"와 면책 문구로 보여준다.
4. **결과 저장** — 로그인한 사용자가 조회 결과를 저장하고 다시 볼 수 있다.

## 데이터 제약
- 실거래가 API는 주택 유형별로 따로 있고 `LAWD_CD`(법정동 5자리)+`DEAL_YMD`(계약월) 단위로 조회된다. 호출 한도가 있어 배치로 수집해 DB에 캐시한다.
- 해제된 거래는 제외한다. 최근 30일치는 신고가 덜 됐다는 점을 결과에 반영한다.
- 면적은 전용면적 기준으로 맞춘다. 지번·도로명 주소를 정규화하는 계층이 필요하다.
- 정책 수치(HUG 기준, 최우선변제금 등)는 바뀔 수 있으므로 구현할 때 최신 기준을 확인한다.

## MVP 범위
- 주택 유형: 아파트, 연립다세대

## MVP 제외 사항
- 다가구·단독주택 — 선순위 보증금을 파악하기 어렵다
- 오피스텔
- 등기부등본, 확정일자 현황, 국세 체납의 자동 조회 — 공개 API가 없다
- KB시세 연동 — 공개 API가 없다
